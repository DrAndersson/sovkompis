# Sovkompis

En lugn, lekfull webbprototyp för att öva inför en andningsregistrering.

**[Öppna Sovkompis](https://drandersson.github.io/sovkompis/)**

Skapa en egen figur, placera åtta utrustningsdelar (inklusive tre EKG-kablar), samla XP och lås upp stjärntröjan efter tre övningar. Figuren avslutar genom att somna med utrustningen på.

Ingen installation eller patientinloggning behövs. 2D-övningen finns kvar, och under ”Din sovkompis” finns en separat [3D-demo](https://drandersson.github.io/sovkompis/demo-3d.html) med två GLB-figurer, rotation, zoom och valbara hår- och klädfärger. Appen anpassar sig till mobil, surfplatta och dator. Dragning, klick och tangentbord stöds. Framsteg sparas i webbläsaren.

Källkod, körinstruktioner och kliniska avgränsningar finns i [sovkompis/README.md](sovkompis/README.md).

GitHub Actions testar och publicerar `sovkompis/dist` till GitHub Pages när ändringar pushas till `main`.

Detta är en övningsprototyp. Mottagningen behöver godkänna innehåll och placeringar för sin utrustning innan den används som patientinstruktion.
